XiaoPrompt

Winner, HackMIT · demo · github

A prompt-distillation API that reduces token usage by 53% while keeping 94% output consistency. We A/B tested condensed prompts against originals using an image-contains-text framework on Gemini outputs, ran the distiller on quantized, energy-efficient models, and built a dashboard of the resulting cost and energy savings.

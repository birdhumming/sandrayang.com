Approaches to the Parallelization of Merge Sort in Python

Alexandra (Sandra) Yang, advised by Gregor von Laszewski · 2022 · arXiv:2211.16479

Work from the UVA Biocomplexity Institute: hybrid parallel merge-sort algorithms in Python using OpenMPI and multiprocessing, optimizing load distribution across distributed and shared-memory systems for up to 34x speedups over the sequential baseline.
